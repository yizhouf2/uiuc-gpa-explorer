    ABOUT THE PROJECT

    About UIUC GPA Explorer

    Author

    Yizhou Fang

    Purpose

    Explore historical grade distributions by course and instructor to inform course selection.

    Where does the data come from?

    This app uses the UIUC GPA Dataset, maintained by Wade Fagen-Ulmschneider. The bundled dataset covers 2010–2025.

    The University of Illinois releases these aggregated grade distributions. Records before Spring 2025 were released through Freedom of Information Act (FOIA) requests. From Spring 2025, the university provides data under Senate item EP.25.072. Some records are withheld to protect student privacy.

    Grade disparity between sections at UIUC is another visualization built from the same dataset.

    Records and chart scope

    Each row is a section-level grade summary with a year, term, course, instructor and grade counts. The chart sums records for the selected course and instructor across the terms listed under “View included terms.” Its vertical axis shows enrollment counts.

    GPA calculation

    Graded enrollments sums A+–F counts. Each course enrollment is counted separately. Weighted GPA equals total grade points divided by graded enrollments. W appears in the chart and is excluded from both calculations.

    Grade points: A+/A = 4.00; A− = 3.67; B+ = 3.33; B = 3.00; B− = 2.67; C+ = 2.33; C = 2.00; C− = 1.67; D+ = 1.33; D = 1.00; D− = 0.67; F = 0.00.

    Missing A+–F counts make the total and weighted GPA unavailable. Zero graded enrollments also produces no GPA. Unavailable values appear as an em dash.
