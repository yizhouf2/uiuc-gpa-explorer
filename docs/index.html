ABOUT THE PROJECT

Course choices, informed by data.

Author

Yizhou Fang

Purpose

This interactive tool explores grade distributions across UIUC departments, courses and instructors, helping students understand historical grading patterns and make informed course decisions.

Data & methodology

The bundled UIUC GPA dataset contains section records from 2010–2025. Each row includes the year, term, subject, course number, title, section type, instructor and letter-grade counts.

GPA uses the original project's weights: A+/A = 4.00, A− = 3.67, B+ = 3.33, B = 3.00, B− = 2.67, C+ = 2.33, C = 2.00, C− = 1.67, D+ = 1.33, D = 1.00, D− = 0.67, F = 0.00. Withdrawals are excluded; sections without graded enrollments display an em dash.

Reference

UIUC GPA Dataset by Wade Fagen-Ulmschneider. The data is a bundled snapshot and does not update automatically.
